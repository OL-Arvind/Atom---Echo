# Information Architecture

## Internal navigation
Command Center · Clients · Content · Calendar · Requests · Tasks · Meetings · Billing · Tools & Renewals · Credentials · Activity · Settings

Some are projections of shared records. Calendar is not a second source of truth.

## Client detail
Overview → active engagement → current work → content → meetings/context → requests/tasks → billing → tools/renewals → credentials (permissioned) → activity.

## Command Center
Needs attention → Today's work → Upcoming → Recent activity.

## Client portal
Separate lightweight surface for review queue, content detail, approve/request changes and relevant request context.

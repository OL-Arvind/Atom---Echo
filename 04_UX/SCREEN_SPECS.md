# Screen Specs — Phase 1

## Command Center
Purpose: attention. Sections: Needs attention, Today's work, Upcoming, Recent activity. Every actionable item has a direct next action.

## Clients
List: client, engagement/status, next action, upcoming date, attention indicators. Detail aggregates operational context.

## Content
Filters: client, state, date, format, pillar. Detail: content, state, dates, assets, reviews/comments, next action.

## Calendar
Week/month/filter views. Project content, meetings, task deadlines, invoices, renewals and milestones.

## Client Review
Mobile-first approve/request changes/comment; no internal navigation.

## Billing
Invoice status, period, retainer, tool expenses, total, due date, send/download.

## Tools
Client, tool, recurring cost, renewal date, billable status, next action.

## Credentials
Masked default; reveal/copy/edit. Permission-check every sensitive action.

## Meetings
Meeting, client, summary/context, proposed actions; each proposal shows what will change, source and confirmation controls.

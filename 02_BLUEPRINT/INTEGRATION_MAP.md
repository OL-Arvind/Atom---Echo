# Integration Map

## Fathom
Meeting context source. Ingest → associate → extract → propose → confirm.

## WhatsApp
Client notification/review-link gateway. Keep provider details behind an adapter.

## Email
Invoice dispatch and selected notifications.

## Notion
Migration/reference during transition. Do not recreate its page editor.

## Google Sheets
Legacy/reference migration source where required.

## LinkedIn / X
External publishing destination. Phase 1 retains final manual publishing control.

## Outreach platforms
Keep Clay/Smartlead and similar systems external in Phase 1.

## Integration contract
Each integration needs adapter boundary, event definitions, retry strategy, idempotency, failure state, auditability and explicit source-of-truth ownership.

# Phase 1 — Operational Core

**Status:** Proposed baseline pending client validation.

## Objective
Make the agency's core operational loop usable without duplicated Notion/database maintenance.

## Included

### 1. Command Center
Actionable attention: overdue/blocked work, today's publishing, renewals, unbilled expenses, review/request exceptions.

### 2. Content Engine + Projected Calendar
Multi-client content, lifecycle, format/pillar, planned/actual dates, unified projection, filters and preview.

### 3. Client Review Portal
Mobile-first secure review, approve/request changes/comment, event-driven state updates and review-link notification.

### 4. Invoicing + Pass-through Tool Billing
Billing dates, draft invoice, retainer, eligible tool expenses, payment state, PDF/export and dispatch.

### 5. Tool Renewal Sentinel
Client tool, cost, cadence, renewal date, billable flag and renewal alert. V1 baseline: 48-hour alert.

### 6. Credential Vault
Encrypted secrets, masking, access control, audited reveal/copy, client scope.

### 7. Fathom Meeting-to-Context
Meeting association, Fathom ingestion, extraction of dates/tasks/content ideas/decisions, confirmation and persistent context.

## Supporting primitives
Clients, engagements, requests, tasks, meetings, activity, permissions, notifications and calendar projection.

## Migration
Migrate agreed operational data from Notion/other sources. Preserve relationships and useful history. Do not migrate everything merely because it exists.

## Phase 1 is operationally complete, not feature-complete.

# Do Not Build

Explicitly outside Phase 1:
- Notion-style page builder;
- generic database builder;
- generic CRM;
- accounting/ERP replacement;
- Clay replacement;
- Smartlead/outreach replacement;
- full social publishing suite;
- complex analytics platform;
- enterprise permission matrix without demonstrated need;
- autonomous personal-branding engine;
- passive social feed/thought capture;
- decorative dashboards;
- complex client chat room;
- duplicate external tools.

## Scope test
> Does this remove meaningful operational friction in the current Atom & Echo workflow, or are we building it because it sounds interesting?

Interesting is not enough.

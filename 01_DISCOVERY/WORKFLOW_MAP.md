# Discovery — Workflow Map

## Content
Current: strategy/idea → client Notion calendar → draft → manual status → WhatsApp/Notion review → manual follow-up → approval/change → manual state updates → publish → manual metrics.

Target: idea → draft → internal review → client review link → approve/request changes → state updates → calendar projection → publishing action → publish.

## Client review
Current: content → WhatsApp → possible Notion access → mobile review → comment → operator updates another system.

Target: content → secure review URL → client action → review event → content transition → related work/activity updates.

## Billing
Current: remember billing date → Google Sheet invoice → send → remember due date → follow up → update status.

Target: billing event → draft invoice → retainer + eligible tool expenses → operator review → send → payment state → overdue attention.

## Tools
Current: manually record cost/renewal → remember renewal → remember invoice inclusion.

Target: subscription → renewal schedule → alert → expense period → invoice line.

## Meetings
Current: meeting → Fathom → human reads → remembers decisions/dates/ideas → manually updates systems.

Target: meeting → Fathom context → extraction → proposed actions → confirmation → state/context updates → history.

## Requests
Current: WhatsApp/message → memory/ad-hoc note → manual follow-up.

Target: request → triage → assignment → execution → review if needed → completion → history.

# Discovery — Friction Map

| Friction | Root cause | OS response |
|---|---|---|
| Separate client calendars | fragmented content state | unified projected calendar |
| Manual status updates | duplicate state | event/state transitions |
| Notion client review | internal tool exposed externally | client portal |
| WhatsApp approval vs system status | disconnected event/state | approval event updates state |
| Invoice dates rely on memory | missing billing workflow | scheduled billing attention |
| Tool costs recalled during invoicing | billing disconnected from tools | subscription → expense → invoice |
| Renewal dates manually remembered | missing operational sentinel | renewal alerts |
| Meeting notes stay notes | context not operationalized | extraction → proposed actions |
| Requests live in chat | no lifecycle/owner | request state machine |
| Credentials scattered | no dedicated secret subsystem | secure credential vault |
| Metrics manually entered | missing integrations | V1 fields; later sync |
| Outreach tooling complex | scope temptation | keep external |

## Diagnostic rule
Fix the underlying fragmentation, duplicated state, missing event, missing automation, unclear ownership, external-tool limitation, or missing context—not merely the screen.

# Discovery — Users & Roles

## Admin / Founder
Needs cross-client visibility, command center, billing, tool renewals, client context, credentials and owner-level settings. Should not maintain duplicate bookkeeping.

## Team Operator
Needs assigned work, content workflow, review queues, requests, meetings/tasks and relevant client context. Should not receive unnecessary financial or credential access.

## Client
Needs simple mobile review, approval, change requests and relevant status. Must not see other clients, internal notes/tasks/financials or broad credentials.

## Principle
Start with a small role model. Increase permission complexity only when the real workflow requires it.
